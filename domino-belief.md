## Die Formel

**VEHICLE + SUPERLATIVE = TRANSFORMATION**

Ausformuliert: "[Vehicle] ist der/die/das [Superlative] Weg zu [Transformation, die sie schon
will]."

Die eine Zeile zum Merken: **das Vehicle ist, was sie BRAUCHT. Die Transformation ist, was sie
schon WILL**, bevor sie je von Katja gehört hat. Steht das, was sie will, links, ist es kein
Glaubenssatz, nur ein Wunsch.

## Die vier (bzw. fünf) Fragen, der Reihe nach

1. **Die Transformation.** Was will Katjas Person schon, bevor sie je von Katja gehört hat, in
   ihren eigenen Worten? (Nicht abstrakt: "sich besser fühlen" reicht nicht.)
2. **Das Vehicle.** Der Mechanismus, den Katja lehrt, der eine, den man auf ein Schild
   schreiben könnte. Kein Schritt darin, kein Feature, nicht der Name eines Programms. Test:
   wenn man alles andere wegnimmt, bringt DAS eine allein die Transformation? Wenn ja, ist es
   das Vehicle. Wenn es nur einer von mehreren Schritten ist, ist es ein Pillar, kein Vehicle.
3. **Das Superlative.** Das Einzige, das Schnellste, das Wirksamste, das Eine. "Ein guter Weg
   zu" reicht nicht, das ist eine Hecke, keine Aussage.
4. **Zusammenfügen** und laut vorlesen.
5. **Kürzen.** Fast jeder erste Versuch ist einen Halbsatz zu lang. Was gekürzt wird, gehört
   woanders hin (ins Versprechen, in einen Pillar, auf die Verkaufsseite), nicht weg.

Danach: die sechs Tests (relevant, glasklar, positiv formuliert, provokant, macht Zustimmung
Lust auf Kauf, in sechs Monaten noch auswendig aufsagbar), dann drei kurze Versionen zur Auswahl.
