# Content

Where finished copy from the Copywriter skill lands. Each command saves here when a piece is
done, instead of getting lost in a chat thread.

## Naming convention

`content/<format>/YYYY-MM-DD-kurztitel.md`

- `<format>` is one of: `newsletter`, `sales-email`, `sales-page`, `social`
- date first, so files sort chronologically
- a short, lowercase, hyphenated title after the date

Example: `content/newsletter/2026-09-07-nervensystem-regulieren.md`

A `sales-email` that's part of a launch sequence gets a shared date and a number:
`content/sales-email/2026-09-10-launch-1-announce.md`,
`content/sales-email/2026-09-10-launch-2-einwand.md`, and so on.
